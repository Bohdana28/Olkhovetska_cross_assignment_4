# Evently

React Native event booking app.

## Components

- CustomButton
- EventCard
- SearchBar
- CategoryList
- BookingItem
- EventInfo
- TabBar

## Technologies

- React Native
- TypeScript
- StyleSheet
- Flexbox
- lucide-react-native

## Responsive Design

The application was tested in portrait and landscape
orientations on iOS and Android.

Responsive dimensions are handled using
useWindowDimensions(), and platform-specific
adjustments are implemented using Platform.select().
